# Contour UI Engineering Documentation

This directory contains the implementation context for the separately deployed
Contour frontend. Planned behavior is not evidence that a feature ships.

1. [Project scope](project-scope.md)
2. [Frontend architecture](architecture/frontend.md)

The repository-root [active task queue](../TASKS.md) holds one bounded working
slice. Accepted cards move to the
[completed-task log](development/task-history.md).

## Documentation boundary

Keep frontend implementation scope, current architecture, API consumption,
setup, browser behavior, testing, and accessibility guidance here. Keep private
research, business strategy, competitor material, raw planning, and superseded
product exploration outside this repository.

When code and docs disagree, resolve the discrepancy explicitly and preserve
the distinction between planned and implemented behavior.
